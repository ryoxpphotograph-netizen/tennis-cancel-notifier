# テニスコート キャンセル通知

各市の施設予約システムを10分ごとに確認し、指定したテニスコートの枠に空きが出たら LINE に通知します。
GitHub Actions 上で動くので、PC の電源を切っていても動き続けます。

| 施設 | 予約システム | 監視条件 |
|---|---|---|
| 三橋総合公園（さいたま市） | [さいたま市施設予約システム](https://saitama.rsv.ws-scs.jp/web/) | 平日 19:00-21:00 |
| 川越運動公園（川越市） | [川越市公共施設予約システム](https://k5.p-kashikan.jp/kawagoe-city/) | 平日 19:00-21:00 |
| 御伊勢塚公園（川越市） | 同上 | 土日祝 9:00-17:00（2時間枠×4） |

- 前回チェック時より空きコート数が増えた枠だけ通知します（同じ空きで何度も通知しません）
- 平日は祝日を除きます
- 初回実行時は、その時点で空いている枠がすべて通知されます
- 予約サイトから取得できない状態が約1時間（6回連続）続くと、LINE で知らせます

## セットアップ

### 1. LINE の準備（10分ほど）

1. [LINE Developers](https://developers.line.biz/console/) に LINE アカウントでログイン
2. プロバイダーを作成 → 「Messaging API」チャネルを作成（LINE公式アカウントが作られます。名前は「テニス空き通知」など自由）
3. チャネルの **Messaging API設定** タブ
   - QRコードを読み取り、自分の LINE でこの公式アカウントを**友だち追加**
   - 一番下の「チャネルアクセストークン（長期）」を**発行**してコピー → `LINE_CHANNEL_ACCESS_TOKEN`
4. （任意）**チャネル基本設定** タブの一番下「あなたのユーザーID」（`U` から始まる文字列）をコピー → `LINE_USER_ID`
   - 登録しない場合は、公式アカウントの友だち全員に送ります。友だちが自分だけなら同じことです。

> 無料プランは月200通まで送れます。この用途なら十分です。

### 2. GitHub の準備

1. GitHub で新しいリポジトリを作成（**Public 推奨**。理由は下記）
2. このフォルダのファイル一式（`.github` フォルダ・`sites` フォルダを含む）をアップロード
3. リポジトリの **Settings → Secrets and variables → Actions → New repository secret** で登録
   - `LINE_CHANNEL_ACCESS_TOKEN`（必須）
   - `LINE_USER_ID`（任意）

  トークンは Secrets に入れるので、Public リポジトリでも他人には見えません。

### 3. 動作確認

**Actions** タブ → 「テニスコート空き監視」→ **Run workflow** で mode を選んで実行:

| mode | 内容 |
|---|---|
| `test-line` | LINE にテストメッセージを送る |
| `dry-run` | 取得した空き状況をログに表示するだけ |
| `run` | 通常の監視（以降は10分ごとに自動実行） |

## 監視条件の変更

`monitor.py` 冒頭の `TARGETS` を書き換えます。

```python
TARGETS = [
    {"name": "三橋総合公園", "site": "saitama", "bld_cd": "4060",
     "days": "weekday", "slots": ["19:00-21:00"]},
    {"name": "川越運動公園", "site": "kawagoe", "shisetsu_code": "057",
     "days": "weekday", "slots": ["19:00-21:00"]},
]
```

- `days`: `"weekday"`（平日）または `"holiday"`（土日祝）
- `slots`: 時間枠。予約サイトの区切りに合わせます
  - さいたま市: `09:00-11:00` `11:00-13:00` `13:00-15:00` `15:00-17:00` `17:00-19:00` `19:00-21:00`
  - 川越運動公園: 上と同じ2時間枠（夜間照明があるのはコート1〜7のみ）
  - 御伊勢塚公園: `09:00-11:00` `11:00-13:00` `13:00-15:00` `15:00-17:00`（A面・B面の2面）
- 川越市の施設で、コート名が「テニスコート」で始まらない場合は `row_prefix` にコート名の先頭を書きます
- 同じ施設を別の条件でも見たい場合は、`name` を変えてもう1行追加します（例: 三橋の土日朝）

さいたま市の他の公園は `bld_cd` を変えれば監視できます（大原テニス公園など）。必要なら相談してください。

## 注意点

- **Private リポジトリの場合**: GitHub Actions の無料枠は月2,000分です。10分ごとだと超えるので、`monitor.yml` の cron を `0 * * * *`（1時間ごと）にしてください。Public なら無制限・無料です。
- GitHub の定期実行は混雑時に数分〜十数分遅れることがあります。
- **60日間リポジトリに更新がないと定期実行が自動停止**します。停止したら GitHub からメールが届くので、Actions タブで再度有効化してください。
- 予約システムへのアクセスは1回あたり数十リクエストで、間隔も空けています。間隔をこれ以上短くするのは避けてください。
- 予約サイトの画面構造が変わると動かなくなります。その場合は LINE に警告が届きます。
